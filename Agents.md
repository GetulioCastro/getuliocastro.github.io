# Landing Page Pessoal — Getúlio Castro Jr

## Tarefa

Criar uma landing page moderna, elegante e responsiva para apresentar **Getúlio Castro Jr** como desenvolvedor de software, evidenciando sua experiência, competências técnicas, trajetória profissional e tecnologias utilizadas no desenvolvimento de sistemas corporativos.

A página deverá transmitir profissionalismo, organização, confiança e paixão por tecnologia, destacando sua atuação tanto no ecossistema Microsoft quanto no desenvolvimento Delphi para aplicações Web.

---

## Objetivo

Desenvolver um site de apresentação profissional (portfólio de uma página) que apresente Getúlio Castro Jr como Desenvolvedor Full Stack com experiência em duas principais stacks de desenvolvimento:

- **C#** com o ecossistema **.NET / ASP.NET Core**
- **Object Pascal (Delphi 12.2)** utilizando o framework **uniGUI** para desenvolvimento de aplicações Web

O site deverá evidenciar:

- Perfil profissional;
- Principais competências técnicas;
- Experiência com desenvolvimento de sistemas corporativos para a área da saúde;
- Capacidade de atuar tanto na manutenção de sistemas legados quanto na modernização e migração para tecnologias Web;
- Interesse constante por aprendizado, arquitetura de software e boas práticas de desenvolvimento.
